# StaffBoard 2.0

Template-based operations board for SPEED, FA Lab, and Bodega.

## Run locally

```bash
npm install
npm run dev
```

Open: http://localhost:8787

## DigitalOcean App Platform

Build command:
```bash
npm install && npm run build
```

Run command:
```bash
npm start
```

Port:
```text
8787
```

## Environment variables

Copy `.env.example` to `.env` and fill DigitalOcean Spaces values if you want server-side state sync.
